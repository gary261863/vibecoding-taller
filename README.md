## 📌 Guía Rápida de Git para la Clase 1

### 1. Clonar el repositorio

Abre tu terminal de comandos (cmd, powershell, etc.)

Verificamos que nos encontremos en el directorio donde queremos clonar con:

```bash
cd [direccion_directorio]
```

ejecuta:

```bash
git clone [URL_repositorio]
cd [nombre_repositorio_clonado]
code .
```

### 2. Crear una nueva rama con tu nombre

```bash
git checkout -b mi-proyecto-nombre
```

### 3. Añadir tu proyecto

```bash
git add .
git commit -m "Añadir propuesta de proyecto de [Tu Nombre]"
```

### 4. Subir tus cambios a GitHub

```bash
git push origin mi-proyecto-nombre
```
